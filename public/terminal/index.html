ALESSANDRO°TERMINAL

A command-driven, multi-window market workspace. Type in the command line, use the launcher at the bottom, or the taskbar up top.

WINDOWS
drag titleMove a window; drag the corner grip to resize
double-clickMaximise / restore a window (title bar)
TILEArrange every open window in a grid
CLOSEClose all windows · UNDO brings them back
COMMAND LINE
NVDAOpen a security window
NVDA GPTicker + function in one line
NovartisAnything else searches the provider's symbol master (name or ticker, all exchanges)
FUNCTIONS
GPPrice graph & security overview
SRCHSymbol search: find any listed instrument, open it, add it to the watchlist
WLWatchlist — add/remove symbols (saved on this device)
MKTMarkets: equities, FX, crypto, metals (real quotes)
MAPS&P 500 heat map: every constituent, sized by index weight, coloured by 1D / 1W / 1M / 3M / 6M / YTD / 1Y change
IDXWorld indices — NO DATA until a licensed source is connected
YLDGovernment yields: U.S. Treasury, ECB euro area
CALEconomic calendar: official BLS / BEA schedules
PFPortfolio: your transactions, positions, value and P&L in EUR (starts empty)
EXCHWorld exchanges: which markets are open now, local time, time to open / close
NNews: FT, Bloomberg, WSJ, MarketWatch, central banks; SEC filings for the watchlist
BRFBriefing: AI summary of the real data above, with sources
MOVMovers: gainers, losers, most active
SCREquity screener with filters
COMPCompare instruments, rebased or % change
CORRCorrelation matrix of daily returns
HEATSector heatmap
SETSettings: colours & themes
HELPThis screen (or press ?)
DATA LABELS · only real data is shown
LIVEReal, from the provider, within its refresh window
PARTReal but partial (volume from a venue subset)
STALEReal but old: the last refresh failed
DRVComputed by the terminal from real data
N/ANo real source: nothing is estimated or invented
